# 校园兼职平台系统简介

## 一、技术栈

**后端**：采用 Spring Boot 3.2.12 框架，结合 MyBatis 实现数据持久化，使用 MySQL 8.0 作为数据库。通过 JWT 实现无状态认证，集成 Spring AI + Ollama 提供本地 AI 推理能力，
支持自然语言交互和智能匹配。

**前端**：基于 Vue 3.5 + Element Plus 构建响应式界面，使用 Vue Router 管理页面路由，Axios 处理 HTTP 请求，ECharts 实现数据可视化。

## 二、核心功能

**用户管理**：支持手机号/用户名注册登录、实名认证（学生/商户）、头像上传、时间偏好设置。

**兼职岗位**：商户可发布兼职信息（薪资、工作时间、结算方式等），学生可浏览、申请、接受兼职岗位。

**AI智能匹配**：根据商户时间需求自动匹配合适的学生，计算匹配度分数，支持空缺填补推荐，提供自然语言交互界面。

**考勤管理**：学生签到签退，商户确认考勤，支持迟到/早退/缺勤标记，自动关联信用分奖惩。

**信用体系**：初始信用分 100 分，完成兼职 +10 分，迟到 -5 分，缺席 -10 分，低于 50 分自动冻结账号。

**消息通知**：系统消息推送、兼职邀请通知、认证结果告知。

## 三、系统亮点

**AI智能匹配**：引入本地 Ollama 大模型，实现基于时间偏好的智能学生匹配，支持自然语言对话交互，提升兼职匹配效率和用户体验。

**完善的信用体系**：建立奖惩分明的信用评分机制，自动关联考勤记录，有效约束用户行为，维护平台秩序。



**完整的考勤闭环**：从学生签到签退到商户确认，支持多种异常考勤状态管理，确保工作记录真实可追溯。

**前后端分离架构**：采用 RESTful API 设计，前端后端独立开发部署，代码结构清晰，易于维护和扩展。

**多角色支持**：同时支持学生、商户、管理员三种角色，满足不同用户群体的使用需求，形成完整的兼职生态。
